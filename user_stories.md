# Expense Tracker – User Stories

## Authentication & User Accounts

As a user, I want to sign up with email/password so that I can have a personal account.
As a user, I want to log in securely so that I can access my personal expenses.
As a user, I want to log out so that I can keep my account safe on shared devices.

## 🌍 Global Usability

As a user, I want to choose my preferred currency so that amounts are displayed in my local money format.
As a user, I want to see correct totals and conversions when I switch currencies.

## 📊 Dashboard & Statistics

As a user, I want a dashboard that shows:
My most recent expenses (e.g., last 5–10).
My total spending today, this week, this month, and this year.
Charts/graphs (bar chart for monthly expenses, pie chart for category breakdown).
A progress indicator for spending limits so I know if I’m close to overspending.
As a user, I want to compare expenses between time periods (e.g., this month vs last month).
As a user, I want to see top spending categories in the dashboard.

## 💸 Expense Management

As a user, I want to add a new expense with title, amount, category, date, and notes.
As a user, I want new expenses to automatically update my totals (daily, weekly, monthly, yearly).
As a user, I want to edit an expense so I can fix mistakes.
As a user, I want to delete an expense so I can remove incorrect or outdated entries.
As a user, I want to categorize expenses (e.g., Food, Bills, Transport) for better organization.
As a user, I want to see a summary of my expenses (e.g., daily, weekly, monthly totals).
As a user, I want to set a spending limit (budget) per month or per category, so I get alerts if I exceed it.
As a user, I want to duplicate/reuse a previous expense entry to save time when adding recurring items.
As a user, I want to attach receipts (images) to expenses for better record keeping (optional but useful).

## 🔍 Filtering, Sorting & History

As a user, I want to filter expenses by:
Date range (e.g., specific month, custom range).
Category (e.g., only “Food”).
Amount (e.g., expenses greater than $100).
As a user, I want to sort expenses by date, amount, or category so I can see them in order.
As a user, I want to view my full expense history to understand long-term spending habits.
As a user, I want to search expenses by keyword (e.g., “Netflix”) so I can find a specific transaction.
As a user, I want to export filtered results only (e.g., last month’s expenses to CSV).

## 🎨 UI/UX & Navigation

As a user, I want to switch between light and dark mode so I can use the app comfortably in different environments.
As a user, I want the app to be responsive so I can use it on desktop, tablet, and mobile.
As a user, I want a sidebar navigation so I can easily switch between sections (Dashboard, History, Profile, Settings).
As a user, I want clear error and success messages (e.g., invalid login, expense saved successfully) so I know what’s happening.
As a user, I want loading indicators when data is being fetched so I know the app is working.
As a user, I want empty states with friendly prompts (e.g., “No expenses yet. Add your first one!”).

## ⚙️ Advanced / Nice-to-Have Features

As a user, I want to export my expenses (CSV, PDF) so I can back them up.
As a user, I want offline support (PWA) so I can add expenses without internet and sync later.
As a user, I want notifications/reminders to log daily expenses so I don’t forget.
As a user, I want to share/export reports (optional for business/personal use cases).
