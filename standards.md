# standards

Radius (Roundness):

Cards / Containers / Modals: rounded-2xl (Big, friendly curves).

Buttons / Inputs / Dropdowns: rounded-xl (Matches the cards, but slightly tighter).

Bad (Don't use): rounded-full (looks like a mobile game), rounded-md (looks too "default/bootstrap").

Shadows:

Cards: shadow-sm (Clean, subtle depth).

Floating (Modals/Dropdowns): shadow-xl.

Bad: shadow-sm (often looks dirty on white cards).

Colors (Slate Theme):

Page Background: bg-slate-50.

Card Background: bg-white.

Primary Brand: bg-indigo-600 (Hover: bg-indigo-700).

Text (Headings): text-slate-900.

Text (Body): text-slate-600 or 700.

Text (Muted/Labels): text-slate-500.

Borders: border-slate-200 (Subtle).

Inputs & Forms:

Background: bg-slate-50 (on white cards) or bg-white (on slate pages).

Border: border-slate-200.

Focus: ring-2 ring-indigo-500 ring-offset-2.

---

🎨 The SpendSignature Design Standard

1. Colors (The "Slate" Theme)

Page Background: bg-slate-50 (Soft, premium feel)

Card Background: bg-white (Clean contrast)

Primary Text: text-slate-900 (Headings, Values)

Secondary Text: text-slate-500 (Labels, Subtitles, Dates)

Brand Color: indigo-600 (Buttons, Links, Active States)

Borders: border-slate-200 (Subtle)

2. Shapes & Spacing (Consistnecy)

Containers/Cards: rounded-2xl + shadow-sm (Modern, friendly look)

Buttons & Inputs: rounded-lg (Classic, functional)

Padding: p-6 for cards, px-4 py-2 for buttons/inputs.

3. Typography

Font: font-sans (Roboto) for everything.

Mono: Only for API keys or credit card numbers. Never for UI text.
