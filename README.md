# SpendSignature 💰

AI-Powered Financial Tracking & Forecasting.

## Features

- **Secure Auth**: Powered by Supabase.
- **AI Insights**: Automated anomaly detection and 3-month forecasting using Google Gemini (Gemma-3).
- **Real-time Analytics**: Interactive charts with Recharts and SQL-optimized data aggregation.
- **PDF Reports**: Exportable category spending history.
